哄

陪你把卡住的 30 秒看懂

在那一秒出现 · 懂前后文 · 讲得短 · 不评判

这个位置还空着。讲完让你接着看，不把课讲浅，也不让你一个人硬扛。

产品理念

「哄」：等你，懂你，然后放手。

等你

只在你暂停时出现

不推送、不打卡、不排名。暂停或按 1 就能问，前后 30 秒的字幕和画面已经读好，你不用重新描述。

你得到：不被催

懂你

先懂全片，再讲这一段

先读完整部视频，知道你卡在哪一章。回答不超过 120 字，固定三段：说人话、打个比方、问你一句。

你得到：不被评判

放手

讲明白就退场

把你送回视频。想自己想通，就切到「带我想」：一次只问一个小问题。

你得到：掌控感

哄，不是把课讲浅，是不让你一个人硬扛。

复盘地图v1.2 已实现

每次求助记成一个节点：视频位置、当时的解释和全部追问。点一下，视频跳回那一秒，对话原样还原，可以接着问。

  • 说人话：谁都不能由其他几个「拼」出来。追问：「含零向量为什么一定相关？」回答：给零向量系数 1，其余取 0，就是一组非零解。
  • 已切到「带我想」。下一个小问题：把矩阵化成阶梯形，非零行有几行？主元所在的列又有几列？
  • 看完解释直接回到视频，没有追问。这就是我们想要的结果：讲明白了，就放你走。

北极星

我们最看重的，
是你多快离开我们。

大多数 App 的北极星是使用时长，越久越好。我们反过来：看完一次解释、没有追问就回到视频，说明那 120 字真的让你看懂了。

北极星指标

看完就关率

看完解释、不追问、直接回到视频的比例。我们不和视频抢你的时间。

暂停›读 120 字›懂了›回到视频

长度违规率

解释超过 120 字的比例。

首字延迟

从求助到看见第一个字的时间。

技术与信任

把可靠写进工程。

三层结构，不绑定任何一家模型。核心是「整片记忆 + 时刻锚定」的上下文，和「哄」的输出纪律。

02 · 本机代理 · 核心

Windows 与 macOS

03 · 任意大模型

模型随你选

任何 OpenAI 兼容的接口都能接，改配置保存即生效。

通义 · DeepSeek · 智谱 · OpenAI

不编造

字幕不够就直说没抓全；读到的字幕和这个视频对不上，就弃用。

不上传

API Key 只在本机代理里，扩展永远拿不到。录音本机识别，用完即丢；学习历史只存在本机浏览器。

不白屏

任何一层失败都有退路：视觉模型不可用就本机读画面文字，没配 Key 就用关键词规则标重点。
